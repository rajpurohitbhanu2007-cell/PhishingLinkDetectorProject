# Phishing Link Detector

A C++ security utility designed to detect and flag potentially malicious or phishing URLs using heuristics and blacklist matching.

## Features
- Fast heuristic analysis of URL structures
- Blacklist verification against known malicious domains
- Lightweight CLI scanner

## How to Build & Run

### Using g++ (MinGW / GCC)
```bash
g++ -O2 Main.cpp -o PhishingDetector.exe
./PhishingDetector.exe
```
